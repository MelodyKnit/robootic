# 📷 相机标定使用指南

本指南介绍如何使用Web界面进行相机自动标定。

## 🎯 标定概述

相机标定是机器视觉系统的关键步骤，用于：
- **内参标定**: 获取相机的内部参数（焦距、主点、畸变系数）
- **手眼标定**: 建立相机坐标系与机器人坐标系的转换关系

本系统提供全自动标定流程，无需手动移动机械臂或调整相机位置。

---

## 🚀 快速开始

### 1. 准备工作

**硬件准备**:
- JAKA Zu 3 机械臂已连接并上电
- Hikvision USB相机已连接
- ChArUco标定板放置在机械臂工作空间内
- 确保标定板固定且清晰可见

**软件准备**:
```bash
# 启动Web服务
poetry run python -m gripper_ai_controller.cli web --config-file config/preview.json
```

### 2. 访问标定界面

打开浏览器访问: `http://127.0.0.1:8000`

在主界面中找到 **"标定 (Calibration)"** 面板。

## 📋 标定流程

### 步骤1: 配置标定参数

在标定面板中配置以下参数：

| 参数 | 说明 | 默认值 | 范围 |
|-----|------|--------|------|
| **工作空间中心X** | 标定板中心X坐标(mm) | 300.0 | - |
| **工作空间中心Y** | 标定板中心Y坐标(mm) | 0.0 | - |
| **工作空间中心Z** | 标定板中心Z坐标(mm) | 100.0 | - |
| **目标图像数** | 期望采集的图像数量 | 30 | 25-50 |
| **最少图像数** | 标定所需的最少图像 | 25 | 10-30 |

**💡 提示**: 
- 工作空间中心应该是标定板的物理位置
- 更多图像可以提高标定精度，但会增加时间
- 最少图像数是标定成功的底线要求

### 步骤2: 启动内参标定

1. 点击 **"启动内参标定"** 按钮
2. 系统会自动生成27个不同的相机位姿
3. 机械臂将依次移动到每个位姿进行图像采集

**位姿分布**:
- **5个距离**: 从近到远覆盖不同焦距
- **5个角度**: 多角度覆盖视野边缘

### 步骤3: 监控标定进度

标定界面提供实时反馈：

**实时预览**:
- 左侧显示当前相机画面
- 检测到的ChArUco角点会高亮显示
- 绿色覆盖层表示检测成功

**3D位姿可视化**:
- 右侧3D画布显示相机轨迹
- 蓝色点: 待采集位姿
- 绿色点: 已完成位姿
- 红色点: 当前位姿

**进度信息**:
- 进度条显示总体完成度
- 位姿计数: `当前/总数`
- 图像计数: `已采集/目标数`
- 当前动作描述

**日志面板**:
- 滚动显示详细日志
- 不同级别使用不同颜色
- 自动滚动到最新日志

### 步骤4: 控制标定流程

标定过程中可以进行控制：

| 按钮 | 功能 | 说明 |
|-----|------|------|
| **暂停** | 暂停标定 | 完成当前位姿后暂停 |
| **继续** | 恢复标定 | 从暂停位置继续 |
| **停止** | 停止标定 | 安全停止并返回初始状态 |

**⚠️ 注意**: 
- 暂停会在当前位姿完成后生效
- 停止后无法恢复，需要重新开始
- 紧急情况请使用机械臂急停按钮

### 步骤5: 查看标定结果

标定完成后会显示结果：

**结果信息**:
```
✅ 标定完成
- 采集图像: 30张
- 重投影误差: 0.35 像素
- 相机矩阵: [fx, fy, cx, cy]
- 畸变系数: [k1, k2, p1, p2, k3]
```

**下载结果**:
- 点击 **"下载结果"** 按钮
- 下载JSON格式的标定参数
- 保存到 `localstore/calibration/` 目录

## 🔧 高级配置

### 标定板参数

ChArUco标定板默认参数（在 `AutoCalibrationConfig` 中定义）：

```python
# 标定板尺寸
squares_x = 8          # X方向格子数
squares_y = 6          # Y方向格子数
square_size = 0.04     # 格子边长(米)
marker_size = 0.03     # ArUco标记边长(米)

# ArUco字典
aruco_dict = cv2.aruco.DICT_5X5_100
```

**自定义标定板**:

如果使用自定义标定板，修改 `build_auto_calibration_plugin` 调用：

```python
from gripper_ai_controller.calibration.auto_intrinsic import AutoCalibrationConfig

config = AutoCalibrationConfig(
    squares_x=10,
    squares_y=7,
    square_size=0.03,
    marker_size=0.022,
    # ... 其他参数
)

plugin = build_auto_calibration_plugin(
    robot_adapter=jaka_adapter,
    vision_adapter=vision_adapter,
    config=config.__dict__,
)
```

### 位姿生成策略

默认生成27个位姿（5距离 × 5角度 + 2正视位姿）：

**距离层级** (相对于工作空间中心):
```python
distances = [0.5, 0.6, 0.7, 0.8, 0.9]  # 米
```

**角度分布**:
```python
tilt_angles = [0°, 15°, 30°, 45°, 60°]  # 俯仰角
pan_range = [-30°, 30°]                  # 左右摇摆
```

**自定义位姿**:

修改 `auto_intrinsic.py` 中的 `_generate_calibration_poses()` 方法。

## 📊 结果文件格式

标定结果保存为JSON格式：

```json
{
  "camera_matrix": [
    [fx, 0, cx],
    [0, fy, cy],
    [0, 0, 1]
  ],
  "distortion_coefficients": [k1, k2, p1, p2, k3],
  "image_size": [width, height],
  "reprojection_error": 0.35,
  "calibration_date": "2026-07-31T12:34:56",
  "images_used": 30,
  "board_config": {
    "squares_x": 8,
    "squares_y": 6,
    "square_size": 0.04,
    "marker_size": 0.03
  }
}
```

**参数说明**:
- `fx, fy`: X和Y方向的焦距（像素）
- `cx, cy`: 主点坐标（像素）
- `k1, k2, k3`: 径向畸变系数
- `p1, p2`: 切向畸变系数
- `reprojection_error`: 重投影误差（像素，越小越好）

## 🐛 故障排除

### 问题1: 检测不到角点

**症状**: 相机画面中看不到绿色高亮的角点

**可能原因**:
- 标定板距离太远或太近
- 光照不足或过强
- 标定板有遮挡或反光
- 相机对焦不准

**解决方案**:
1. 调整标定板位置到合适距离（0.5-1.0米）
2. 改善照明条件，避免强光直射
3. 清洁标定板表面，去除遮挡物
4. 手动调整相机对焦（如果支持）

### 问题2: 标定失败

**症状**: 提示"标定失败"或重投影误差过大

**可能原因**:
- 采集的有效图像数量不足
- 图像中角点分布不均匀
- 相机移动过程中抖动

**解决方案**:
1. 增加目标图像数（40-50张）
2. 降低移动速度（减少抖动）
3. 确保标定板固定牢固
4. 重新标定并仔细观察每个位姿的检测结果

### 问题3: 机械臂移动异常

**症状**: 机械臂不移动或移动到错误位置

**可能原因**:
- 机械臂未正确初始化
- 工作空间参数配置错误
- 碰撞检测触发

**解决方案**:
1. 检查机械臂连接状态
2. 验证工作空间中心坐标
3. 确保工作空间内无障碍物
4. 重启机械臂和Web服务

### 问题4: WebSocket连接断开

**症状**: 进度条不更新，日志停止滚动

**可能原因**:
- 网络问题
- 浏览器休眠
- 服务端崩溃

**解决方案**:
1. 刷新浏览器页面（会自动重连）
2. 检查控制台错误信息
3. 查看服务端日志
4. 重启Web服务

## 📝 最佳实践

### 标定前准备

1. **环境检查**:
   - 充足且均匀的照明
   - 无强光直射或反光
   - 标定板固定且平整

2. **参数设置**:
   - 首次标定使用默认参数
   - 根据实际效果调整距离和角度
   - 重投影误差目标 < 0.5像素

3. **测试运行**:
   - 先手动移动机械臂确认安全
   - 小范围测试几个位姿
   - 确认无碰撞风险后再全流程运行

### 标定质量评估

**优秀标定** (reprojection_error < 0.3):
- 图像覆盖充分（30+张）
- 多角度多距离均匀分布
- 每张图像检测到足够角点（50+）

**良好标定** (0.3 < reprojection_error < 0.5):
- 满足基本使用要求
- 可用于一般精度的视觉任务

**需要重新标定** (reprojection_error > 0.5):
- 精度不足
- 建议增加图像数量或改善采集条件

### 标定周期

**何时需要重新标定**:
- 相机位置或角度发生变化
- 相机镜头更换或调整焦距
- 发现视觉测量误差增大
- 定期维护（建议每月一次）

## 💬 常见问题

**Q: 标定需要多长时间？**  
A: 大约5-10分钟，取决于位姿数量和机械臂移动速度。

**Q: 可以在标定过程中关闭浏览器吗？**  
A: 不建议。标定在后端运行，但关闭浏览器会丢失实时反馈。可以暂停后再关闭。

**Q: 标定结果保存在哪里？**  
A: `localstore/calibration/{calibration_id}_intrinsic.json`

**Q: 支持多个相机同时标定吗？**  
A: 当前版本仅支持单相机标定。多相机需要依次标定。

**Q: 手眼标定什么时候实现？**  
A: 手眼标定功能正在开发中，将在后续版本中提供。
