# 自动标定Web插件设计方案

## 📋 设计目标

将自动标定功能集成到Web界面，提供**可视化、交互式、实时反馈**的标定体验。

## 📡 API设计

### REST API

```python
# 标定控制
POST   /api/calibration/intrinsic/start    # 启动内参标定
POST   /api/calibration/intrinsic/pause    # 暂停
POST   /api/calibration/intrinsic/resume   # 恢复
POST   /api/calibration/intrinsic/stop     # 停止
GET    /api/calibration/intrinsic/status   # 获取状态

POST   /api/calibration/handeye/start      # 启动手眼标定
GET    /api/calibration/handeye/status     # 获取状态

# 配置管理
GET    /api/calibration/config              # 获取配置
PUT    /api/calibration/config              # 更新配置

# 结果管理
GET    /api/calibration/results             # 列出历史结果
GET    /api/calibration/results/{id}        # 获取特定结果
DELETE /api/calibration/results/{id}        # 删除结果
```

## 🎯 核心特性

### 1. 向导式流程
- ✅ 分步引导（准备→内参→手眼→验证→完成）
- ✅ 每步验证，不满足条件无法进入下一步
- ✅ 支持返回修改配置

### 2. 实时反馈
- ✅ WebSocket推送采集进度
- ✅ 实时相机预览（标定板检测可视化）
- ✅ 3D位姿可视化（已采集/当前/待采集）
- ✅ 滚动日志显示

### 3. 交互控制
- ✅ 暂停/恢复标定
- ✅ 停止并保存当前进度
- ✅ 跳过失败位姿
- ✅ 调整采集参数

### 4. 结果管理
- ✅ 标定结果可视化展示
- ✅ 下载JSON配置文件
- ✅ 历史记录查看
- ✅ 精度验证报告

### 5. 错误处理
- ✅ 友好的错误提示
- ✅ 可恢复错误自动重试
- ✅ 严重错误提供解决建议

## 📊 状态机设计

```
                    ┌─────────┐
                    │  Idle   │ 初始状态
                    └────┬────┘
                         │ start()
                    ┌────▼────┐
                    │  Ready  │ 准备就绪
                    └────┬────┘
                         │ begin()
                    ┌────▼─────┐
           ┌────────┤ Running  │ 执行中
           │        └────┬─────┘
           │             │ pause()
           │        ┌────▼────┐
           │        │ Paused  │ 已暂停
           │        └────┬────┘
           │             │ resume()
           │             ├──────────────┐
           │             │              │
    stop() │        ┌────▼─────┐  ┌────▼────┐
           └───────►│ Complete │  │  Error  │
                    └──────────┘  └─────────┘
```

## 💡 用户体验优化
