# 领域合约

`domain` 包含不可变的、硬件无关的数据结构和抽象端口。必须保持不含厂商 SDK 导入、适配器特定分支逻辑和应用程序配置。

## 公开合约

- `models.py`：指令、遥测、姿态、标定、视觉观测、相机设备与参数描述、组件元数据和执行报告。
- `ports.py`：面向机器人、夹爪和视觉适配器的生命周期化合约，以及可选的 `CameraParameterAdapter` 受限参数端口和 `SelectableVisionAdapter` 设备选择端口。

所有适配器将其原生 API 转换为这些数据结构。规划器和感知插件消费和产出这些数据结构。这使得同一算法可在模拟设备和物理设备上使用。`CameraParameterAdapter` 与 `VisionAdapter` 取帧端口刻意分离：前者只能返回白名单参数并接收规范化标量更新，不能把厂商客户端或任意节点名传到网页层。`SelectableVisionAdapter` 同样是可选能力，只能枚举浏览器安全的设备描述并在停止态配置不透明设备 ID；启动、回滚和持久化属于上层服务职责。

添加稳定的跨模块字段时，请更新其数据类的文档字符串和本 README，然后添加兼容性测试。
